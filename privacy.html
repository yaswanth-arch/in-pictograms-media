Privacy policy

Last updated 26 November 2026

"In Pictograms publisher" is a private tool used only by the owner of the In Pictograms YouTube channel to publish the channel's own films. It is not offered to anyone else.

What it accesses

With the channel owner's permission, the tool uses YouTube API Services to upload the channel's videos, set their titles, descriptions, thumbnails and playlists, read the channel's own view statistics (YouTube Analytics), and read and reply to comments on the channel's videos.

What it stores

The sign-in token is stored only on the channel owner's own computer. Video statistics are kept there to choose future topics. Nothing is stored on any server run by this tool.

Sharing

No data is sold, shared with or transferred to anyone. The tool collects no information about viewers beyond what YouTube shows any channel owner, such as public comments.

YouTube and Google

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions about this policy: through the In Pictograms channel page.
